

# File Integrity Checker

A Python-based cybersecurity tool that verifies the integrity of application and log files using SHA-256 cryptographic hashing.

## Features

- Accepts a single file or an entire directory.
- Calculates SHA-256 hashes for files.
- Stores hashes for future integrity checks.
- Detects modified files using hash comparison.
- Detects new and deleted files.
- Allows authorized users to update stored hashes.
- Provides clear terminal output.

## Requirements

- Python 3.8 or later
- No external Python packages are required.
